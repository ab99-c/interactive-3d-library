تجربة مكتبة 3D تفاعلية بحال لعبة، مبنية بــ React وBabylon.js. اللاعب يقدر يتحرك داخل القاعة باستعمال `W A S D` أو الأسهم، ينظر بالماوس، وينقر على الكتب باش يفتح بطاقة معلومات قصيرة.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

افتح الرابط المحلي اللي كيعطيه Vite. لفحص بصري deterministic استعمل المسار `/?demo`.

## الأوامر

```bash
pnpm check
pnpm build
```

## البنية

العالم 3D موجود في `client/src/game/scene.ts`، ودمج Babylon مع React والـ HUD موجود في `client/src/components/GameCanvas.tsx`. الأصول البصرية الكبيرة كتستعمل روابط التخزين الخاصة بالمشروع، وما خاصهاش تتحط داخل `client/public`.

## النشر على Vercel

المشروع Vite static، لذلك يمكن ربط repository الجديد بمشروع Vercel. أمر build هو `pnpm build`، ومجلد الخرج هو `dist/public` حسب إعدادات القالب. قبل النشر، شغّل `pnpm check` و`pnpm build` وتأكد من فتح `/` وإعادة تحميله.

## الحالة الحالية

النسخة الحالية فيها قاعة أندلسية كاملة، رفوف حجرية بخلفيات مرصوفة وشمعدانات، ٧٢٠ مجلداً بستة عشر عنواناً من التراث العربي، طاولات دراسة بأسطرلاب ومحبرة، سلالم ومساند أقدام، حركة منظور الشخص الأول مع يدين متحركتين، اصطدامات، تفاعل بالنقر، HUD عربي وتعليمات، ودعم كامل للهاتف بعصا تحكم افتراضية.

### طبقة اللعب — رحلة الباحث

- **الأهداف المتسلسلة**: من «الخطوات الأولى» حتى «أمين المكتبة» — تجوال، افتتاح كتب، تقليب صفحات، وقراءة حي بن يقظان.
- **نقاط المعرفة والرتب**: زائر القاعة ← قارئ ← باحث ← عالِم ← حكيم المكتبة، مع إشعارات إنجاز ونغمات نحاسية.
- **الحفظ بين الجلسات**: التقدم والصوت وموضع القراءة يُحفظون في المتصفح، مع زر إعادة ضبط داخل بطاقة الأهداف.
- **الصوت**: أجواء القاعة (همهمة منخفضة)، خطوات المشي والجري، سحب/إرجاع الكتاب، وتقليب الصفحات — كلها مولّدة في المتصفح بدون أصول خارجية. زر كتم الصوت في شريط الأزرار.
- **خريطة القاعة**: خريطة SVG مصغّرة تُظهر الرفوف وموضع اللاعب.
- **ذرات غبار ضوئية** في الوضع السينمائي، وتُعطَّل تلقائياً في وضع الأداء الخفيف أو مع `prefers-reduced-motion`.

الميزات خارج النطاق حالياً هي اللعب الجماعي والألغاز والشخصية المرئية من منظور ثالث.
